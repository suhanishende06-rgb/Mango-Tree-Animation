# Mango Tree Animation 🌳🥭

An interactive animated mango tree project built using HTML, CSS, and JavaScript. This project showcases a beautiful nature scene with a moving mango tree, animated children playing under the tree, falling leaves effects, and clickable mango animations. The smooth animations and colorful village environment make the project visually attractive and beginner friendly for frontend animation practice and GitHub portfolios.

## Features

- Swinging mango tree animation
- Animated children movements
- Falling leaves effect
- Clickable mango interaction
- Smooth CSS animations
- Beautiful nature background

Built using HTML, CSS & JavaScript.
